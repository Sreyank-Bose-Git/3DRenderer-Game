# Security Policy

## Supported Versions

This project is under active development, and only the latest code on the default branch is considered supported for security updates.

## Reporting a Vulnerability

If you discover a security issue, please report it responsibly:

1. Do **not** open a public issue with exploit details.
2. Contact the maintainer privately through GitHub.
3. Include:
   - A clear description of the issue
   - Reproduction steps
   - Potential impact
   - Suggested remediation (if available)

## Response Expectations

- Acknowledgement target: within 7 days
- Initial triage target: within 14 days
- Fix timeline: depends on severity and complexity

Thank you for helping keep this project and its users safe.
